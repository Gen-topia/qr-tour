# 디자인 변경 지시 (Claude Code에 붙여넣기용)

아래 내용을 Claude Code에 그대로 붙여넣으면 됩니다.

---

`reference/` 폴더의 이미지를 참고해서 이 앱의 전체 디자인 톤을 그에 맞게 바꿔줘.

작업 기준:
1. 먼저 `reference/screens/`와 `reference/inspiration/`의 이미지를 보고, 팔레트(배경/주색/보조색/텍스트)·타이포·모서리·그림자·여백 밀도·무드를 추출해줘.
2. `docs/디자인_가이드.md`의 토큰 시스템을 기준으로, `src/app/globals.css`의 `:root` 변수부터 그 값에 맞게 수정해줘. 색 이름과 실제 색이 안 맞으면 주석도 갱신.
3. 토큰만으로 안 되는 부분(버튼 스타일, 카드 그림자, 탭바 모양, body 배경 그라데이션, 폰트)은 해당 클래스를 조정. 폰트 교체가 필요하면 next/font로 로드해 연결.
4. 규칙: **className/구조는 유지**(색·폰트·형태만 변경), **모바일 360px가 안 깨지게**, **텍스트 대비(가독성) 확보**. 밝은 테마로 뒤집을 땐 --ink/--paper 관계를 재점검.
5. 먼저 메인 화면(`/`) 기준으로 맞춘 결과를 보여주고, 내가 확정하면 나머지 화면(quest/missions/scan/admin)까지 확장해줘.

작업 후 `npm run build`로 깨지지 않는지 확인해줘.

---

## 참고
- 특정 색을 꼭 쓰고 싶으면 위에 한 줄 덧붙이세요: 예) "메인 컬러는 #FF6B6B, 배경은 밝은 아이보리로."
- 특정 화면만 바꾸려면: "reference/screens/quest.png 만 참고해서 미션 화면만 바꿔줘."
